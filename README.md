HSK1 - Ứng Dụng Học Tiếng Trung & Giải Mã Hán Tự
Ứng dụng web học tiếng Trung tĩnh, tối ưu hóa cho màn hình điện thoại, vận hành trực tiếp trên GitHub Pages.
Trang web chính thức: https://bohoa96tb.github.io/HSK1/
Nền tảng triển khai: GitHub Pages (Web tĩnh: HTML5, CSS3, JavaScript ES Modules, PWA).
1. Khu Vực Từ Vựng Hiện Tại (HSK 1)
Học từ vựng theo từng bài học trực quan (data/hsk1/bai-*.js).
Hỗ trợ phát âm, phiên âm Pinyin, nghĩa tiếng Việt và ví dụ minh họa.
Hoạt động nhẹ nhàng trên thiết bị di động, không cần cài đặt phần mềm phức tạp.
2. Khu Vực Sắp Nâng Cấp: Giải Mã Hán Tự (hanzi/)
Dự án đang trong lộ trình phát triển phân hệ Giải mã Hán tự đa tầng (lấy cảm hứng từ mô hình nhận thức của Hanly: Chinese Decoded) với các tính năng cốt lõi:
Phân rã cấu trúc: Bóc tách chữ thành các bộ thủ và cấu kiện biểu ý / biểu âm theo chuẩn IDS.
Tập viết tương tác: Hướng dẫn quy tắc bút thuận, mô phỏng hoạt ảnh và chấm điểm nét vẽ trên ô Mễ tự cách / Điền tự cách.
Tiến hóa văn tự & Từ nguyên: Trực quan hóa diễn biến hình thể từ Giáp cốt văn, Kim văn, Tiểu triện đến Khải thư hiện đại.
Ghi nhớ ngắt quãng (FSRS): Thuật toán tối ưu hóa lịch ôn tập khoa học, lưu trữ ngoại tuyến qua IndexedDB (PWA).
